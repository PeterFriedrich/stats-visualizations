## 3. Technical Learnings
- **No Math 20-1 formula sheet exists** (there is no diploma exam). Notation authority is the textbook, which the owner has not yet confirmed.
- **Answers are hidden until the last step on purpose**, so the sim works for "try it on paper first" tutoring (ARCHITECTURE §7).
- **Negative k is drawn as area taken away:** two strips of width h overlap in a corner that gets taken twice, so +h² goes back. Strip pixel width = clamp(|h|·22, 14, 100) (max 80 when negative). The x side is a fixed 190 design units because x is unknown.
- **Area-model animation** eases a continuous stage `g` toward the current step's `g` at 2 stages/s using `performance.now()`. It is display only, not randomness, and jumps under reduced motion.
- **Rationals in `quadratic.js` are reduced `[n, d]` with d > 0.** `+ 0` turns −0 into 0, because `assert.deepEqual` distinguishes them. `probability.js` fractions are deliberately unreduced, so don't mix the two.
- **Server quirks are unchanged from S01:** run the guards with `python3.12`, and prefix Playwright with `NODE_PATH=/home/opc/edmonton-tax-viz/tools/profiling/node_modules`. Headless Chromium here renders the sans font as a monospace-looking fallback (all sims), so judge layout, not typeface, from screenshots.
- `npm run serve` serves on :8000. A background serve started via Bash could not be `pkill`ed (exit 144); it may still be running.
- **Renaming the repo changes the Pages URL** (`/stats-visualizations/`). It is unverified whether GitHub redirects the old Pages URL; check before renaming. The local dir, rc-session name and the `/home/opc/CLAUDE.md` row (owned by the `server` session) would all follow.
