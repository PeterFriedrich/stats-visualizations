## 3. Technical Learnings
- **Randomness rule differs from the sibling sites.** There, random motion is decoration. Here sampling is the subject: every draw goes through a seeded `rng` (`stats/random.js`, mulberry32 + Box–Muller), the seed is on screen, and a simulated readout sits beside its exact value. A run must depend on the seed only: `bessel` draws "sample k" in order, `floor(clock.t × RATE)`, so frame timing cannot change it. ARCHITECTURE.md §4.
- **The PyQt Bessel demo resampled from a pool of 100 000 normal draws**, whose own variance was not exactly σ². The port draws straight from N(μ, σ²).
- **Formula sheets** were taken from the 2025–2026 diploma information bulletins (URLs in `docs/DATA_SHEET.md`). ⚠️ Transcribed from the PDF **text layer** via pypdf, which drops the bar in P(B | A) and scrambles stacked fractions. Not yet checked against the rendered page. Neither sheet prints odds, the complement rule, the counting principle or the repeated-elements formula.
- **Mathematics 30-2 "Probability" includes counting, permutations and combinations**, hence the shared sims. STAT 151 unit titles are my split of the U of A calendar description, not an official unit list. The owner writes "STATS 151"; the calendar name is STAT 151.
- **Static sims** (everything but `bessel`) still call `createClock` for the redraw loop and set `ui.transport.hidden = true`.
- **Phone width is where the layouts broke.** Centred one-line text overflowed in `permutations`, `combinations` and `venn`; `para()` wraps it. Re-check 390 px after any change to on-canvas text.
- **Two readout sets in one sim** (`permutations`, `combinations`): call `readouts()` twice and toggle each `<dl>`'s `hidden`.
- **Server quirks:** system `python3` is 3.6, so `npm run check` fails at the guards here; run `python3.12 scripts/check_doc_citations.py` and `python3.12 scripts/check_decisions_log.py`. Playwright is not global: prefix `NODE_PATH=/home/opc/edmonton-tax-viz/tools/profiling/node_modules`. No `pdftotext`/`pdftoppm`, so the Read tool cannot open PDFs; I used pypdf in a scratch venv.
